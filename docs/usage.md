# 使用说明

## 准备内容与账号

在设置页选择内容目录。目录中的每个一级子文件夹代表一条内容，推荐使用 `YYYY-MM-DD_标题` 命名。视频、字幕、封面、文章和其他素材都由用户直接在文件夹中维护；工作台会列出全部候选文件。

点击侧边栏的“新建内容”时，需要在视频、音频、图文中单选一种内容类型，默认选择视频。选择结果保存在新目录的隐藏文件 `.oil-content.json` 中；旧目录没有该文件时继续按素材自动识别，不影响使用。

视频模式至少选择：

- 一个 `.mp4` 或 `.mov` 视频；
- 一个可选的 `.srt`、`.ass`、`.vtt` 或 `.txt` 字幕。

文章模式至少选择一个 Markdown 和一张 PNG/JPEG/WebP 封面。文章可放在内容子文件夹根目录或 `公众号文章/` 中。

打开设置页的平台账号区域：

1. 点击“登录账号”，工作台会为对应平台打开独立 Ego Browser 任务空间；
2. 在浏览器中自行输入账号、密码、验证码或扫码；
3. 回到工作台点击“完成并检查”；
4. 页面访问创作者工作台并记录当前会话是否可用。

24 个平台都提供账号入口。网易云音乐与喜马拉雅听位于音频平台组，目前只提供账号登录与检查，不参与自动草稿。当前可分发目标为 B站、抖音、小红书、视频号和微信公众号；其他平台保留为后续适配目录。

## 内容详情的两步流程

“概览”只展示封面、当前状态和时间等预览信息，不包含文件选择、平台选择或草稿操作。

### 1. 选择内容文件

进入“视频”页选择本地视频和可选字幕，或进入“图文”页选择 Markdown 和封面；所选类型的预览会显示在当前页。

### 2. 选择平台并创建草稿

在同一页的第二步选择已启用且账号有效的平台。平台卡片同时显示 Ego 登录状态和草稿状态。若本次确实拥有原创权益，可以勾选明确确认；随后点击“一键生成并保存草稿”。

工作台把任务排入当前 Harness 会话。AI 按平台约束生成字段并调用冻结工具，随后 Ego 执行草稿动作。视频先使用 `video-publisher` 安全运行器到达投稿页 `READY`；B站点击“存草稿”并从草稿箱回读 `draftId`，抖音点击“暂存离开”后从 draft 入口核对标题并回读 `video_id`。微信公众号内置适配器已经实现保存与 `appmsgid` 回读，但目前只有模拟回归证据，完成真实账号验证前不宣称远端闭环。所有路径都停在最终发表前。

如果平台只显示“页面已备，尚未远端保存”，说明投稿页内容已通过验证，但平台的远端保存器尚未完成真实回归；这不是草稿成功。当前 B站和抖音具备真实远端草稿 id 回读证据。

## 常见问题

### 登录成功但不能勾选平台

账号绑定与自动草稿是两层能力。该平台尚无已验证的草稿适配器时，只能保存登录会话，不能启动自动草稿。

### 草稿按钮不可用

检查是否已选齐当前模式的素材、目标平台是否启用且账号已登录，以及当前是否打开了 Harness 会话。用户不需要准备 `publish-package.json`。

### 原文件会被修改吗

原始素材不会被修改。Harness AI 的平台变体会写入内容文件夹中的 `.oil-distribution.json`，这是可审计、可重试的 sidecar；重试不会重新改写文案。
