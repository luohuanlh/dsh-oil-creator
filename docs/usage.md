# 使用说明

## 准备内容与账号

在设置页选择内容目录。目录中的每个一级子文件夹代表一条内容，推荐使用 `YYYY-MM-DD_标题` 命名。视频、字幕、封面、文章和其他素材既可以由用户直接放入内容文件夹，也可以在工作台对应素材旁点击“本地文件”导入；工作台会列出全部候选文件。

点击侧边栏的“新建内容”时，需要在视频、音频、图文中单选一种内容类型，默认选择视频。选择结果保存在新目录的隐藏文件 `.oil-content.json` 中；旧目录没有该文件时继续按素材自动识别，不影响使用。

视频模式至少选择：

- 一个 `.mp4` 或 `.mov` 视频；
- 一个可选的 `.srt`、`.ass`、`.vtt` 或 `.txt` 字幕。

文章模式至少选择一个 Markdown 和一张 PNG/JPEG/WebP 封面。文章可放在内容子文件夹根目录或 `公众号文章/` 中。

“本地文件”会把所选文件复制到当前内容文件夹，不会修改源文件。视频采用流式导入，支持最大 16 GB；字幕最大 20 MB，Markdown / HTML 文章最大 2 MB，PNG/JPEG/WebP 封面最大 20 MB。同名文件不会被覆盖，而会自动生成 `文件名-2.ext`、`文件名-3.ext` 等新名称。

打开设置页的平台账号区域：

1. 点击“登录账号”，工作台会为对应平台打开独立 Ego Browser 任务空间；
2. 在浏览器中自行输入账号、密码、验证码或扫码；
3. 回到工作台点击“完成并检查”；
4. 页面访问创作者工作台并记录当前会话是否可用。

平台定义仍保留网易云音乐与喜马拉雅听，但设置页暂不展示音频平台账号入口。当前可分发目标为 B站、抖音、小红书、视频号、快手、微信公众号和百家号。其余十四个图文 Adapter（企鹅号、网易号、一点号、大鱼号、顶端新闻、雪球号、东方财富号、同顺号、搜狐号、微博、知乎、维科网、老虎财经、富途牛牛）已有本地契约测试，但仍缺真实账号保存与回读证据，因此显示“实现完成，待真实回归”且不能勾选。

## 内容详情的两步流程

“概览”只展示封面、当前状态和时间等预览信息，不包含文件选择、平台选择或草稿操作。

### 1. 选择内容文件

进入“视频”页选择已有视频和可选字幕，或通过旁边的“本地文件”导入新素材；视频封面也可作为当前内容的可选素材导入。已选封面比例不符合平台要求时，工作台会在 Mac 或 Windows 上使用本地图片处理自动居中裁切出 3:4、4:3 或两种派生文件，原图不会被修改，也不会静默改用 AI 封面。B站没有选择封面时，运行器才会调用 B站自己的 AI 封面流程。进入“图文”页时选择或导入 Markdown / HTML 文章和封面。导入完成后，新文件会自动成为当前选择，所选类型的预览会显示在当前页。

### 2. 选择平台并创建草稿

在同一页的第二步选择已启用且账号有效的平台。平台卡片同时显示 Ego 登录状态和草稿状态，随后点击“一键生成并保存草稿”。若运行器需要原创/自制声明且当前配置要求逐次确认，Harness 会在任何平台写入前要求用户明确确认；不得从文件名或素材内容推断原创权。

工作台把任务排入当前 Harness 会话。AI 按平台约束生成字段并调用冻结工具，随后 Ego 执行草稿动作。一次点击最多把 B站、抖音、小红书、视频号和快手交给同一个 `video-publisher` 作业；页面检查、视频上传和最终核验五平台并发，标题、标签、封面及远端保存按共享输入通道串行。B站点击“存草稿”并从草稿箱回读 `draftId`，抖音点击“暂存离开”后从 draft 入口核对标题并回读 `video_id`，快手从服务器未发布快照回读 `fileId` 并核对文件名与精确描述。微信公众号与百家号内置适配器分别回读 `appmsgid` 和 `article_id`；目前二者都只有模拟回归证据，完成真实账号验证前不宣称远端闭环。两个图文适配器使用独立 Ego 任务空间并发运行，结果逐平台写回，所有路径都停在最终发表前。

如果平台只显示“页面已备，尚未远端保存”，说明投稿页内容已通过验证，但平台的远端保存器尚未完成真实回归；这不是草稿成功。当前 B站、抖音和快手具备真实远端草稿 id 回读证据。

## 常见问题

### 登录成功但不能勾选平台

账号绑定、Adapter 实现证据和自动草稿开放是三层能力。`local-tested` 只表示生产脚本通过本地 fixture，不代表真实平台已经保存草稿；只有平台定义配置了 `draftRunner` 才能勾选。十四个隐藏图文 Adapter 完成真实草稿回归前都保持禁用。

### 草稿按钮不可用

检查是否已选齐当前模式的素材、目标平台是否启用且账号已登录，以及当前是否打开了 Harness 会话。用户不需要准备 `publish-package.json`。

### 原文件会被修改吗

原始素材不会被修改。“本地文件”只在内容文件夹中创建副本，发生重名时自动增加数字后缀。Harness AI 的平台变体会写入内容文件夹中的 `.oil-distribution.json`，这是可审计、可重试的 sidecar；重试不会重新改写文案。
