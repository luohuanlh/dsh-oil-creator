# 内容文件夹约定

一个一级子文件夹代表一条内容。推荐命名为 `YYYY-MM-DD_可读标题`。

```text
内容目录/
└── 2026-08-21_可读标题/
    ├── video.mp4
    ├── subtitle.srt
    ├── cover_3x4.png
    ├── .oil-distribution.json
    └── 公众号文章/
        ├── 可读标题.md
        └── images/
```

## 工作台识别的文件

| 文件 | 用途 |
| --- | --- |
| `*.mp4` / `*.mov` | 工作台可选的视频 |
| `*.srt` / `*.ass` / `*.vtt` / `*.txt` | 视频模式可选的语义字幕输入 |
| `*.md` / `公众号文章/*.md` | 工作台可选的文章 |
| `*.png` / `*.jpg` / `*.jpeg` / `*.webp` | 工作台可选的文章封面 |
| `.oil-distribution.json` | Harness AI 提交的平台变体和固定素材选择；由工作台原子生成 |

原始磁盘文件是素材真相来源。插件不自动生成、移动或删除它们，也不把正文复制到 overlay。AI 平台变体单独冻结，Ego 重试只消费冻结结果。

## 插件状态

插件数据目录中的 `overlay.json` 只保存：内容目录路径、创作者档案、启用平台、Ego Browser 账号检查结果，以及逐平台草稿任务状态。只有远端保存并回读成功的平台才记录 `remoteId` 与草稿 URL；仅达到投稿页 READY 的平台记录 `draftState=ready`。视频运行器会从冻结分发包派生临时兼容包；原始素材不变。
